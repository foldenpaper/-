# 今天吃什么 🍲

一个安卓手机上用的"今天吃什么"转盘小网页（PWA），可以安装到手机桌面，全屏打开，离线也能用。

## 功能

- 转盘抽签：指针所指与结果文字严格一致，可连续抽到同一项，转动中自动防连点
- 四个分类：正餐 / 轻食 / 宵夜 / 下午茶，各有一份菜单
- ✏️ 编辑选项：增删改，2～12 项，每项最多 8 个字，可一键恢复默认
- 🕘 最近 5 次抽签记录
- 🔇/🔊 音效开关（默认关闭，用 Web Audio 合成，无音频文件）；抽中时手机轻震一下
- 以上设置都保存在手机本地（localStorage），清除浏览器数据后会恢复默认

纯 HTML + CSS + JavaScript，没有任何依赖，不需要构建，把文件放到任意静态托管平台就能上线。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 样式与动效 |
| `app.js` | 转盘绘制、角度算法、防连点、安装按钮 |
| `manifest.webmanifest` | PWA 应用信息（名称、图标、全屏） |
| `sw.js` | 离线缓存 |
| `icons/` | 桌面图标（真实 PNG，含 maskable 版本） |
| `tools/gen-icons.js` | 重新生成图标的脚本（开发用） |
| `tools/test-wheel.js` | 自动校验脚本（开发用） |

## 在电脑上预览

在项目根目录运行：

```bash
python3 -m http.server 8000
```

然后用 Chrome 打开 <http://localhost:8000/>，按 F12 打开开发者工具，点"手机"图标切换成安卓手机尺寸。

> 直接双击 `index.html` 也能用转盘，但离线缓存和"安装到桌面"只能在 `http://localhost` 或 `https://` 网址下生效。

## 免费上线（任选其一）

### 方法一：GitHub Pages（代码已在 GitHub 上时最省事）

1. 打开 GitHub 仓库页面，点 **Settings → Pages**。
2. **Source** 选 "Deploy from a branch"，**Branch** 选放这些文件的分支，文件夹选 `/ (root)`，点 Save。
3. 等 1~2 分钟，页面顶部会显示网址，形如 `https://用户名.github.io/仓库名/`。

### 方法二：Cloudflare Pages

1. 登录 Cloudflare 控制台，进入 **Workers & Pages → 创建 → Pages**。
2. 选"上传资源"（直接拖整个文件夹），或连接 GitHub 仓库（构建命令留空，输出目录填 `/`）。
3. 部署完成后会得到 `https://xxx.pages.dev` 网址。

## 在安卓手机上安装到桌面

1. 用 **Chrome** 打开上线后的网址。
2. 页面按钮下方会出现 **「安装到桌面」**，点它确认即可。
   - 如果没出现，点 Chrome 右上角 **⋮ → 添加到主屏幕 / 安装应用**。
3. 之后从桌面图标打开就是全屏的 App。

## 更新版本

修改代码后重新部署时，把 `sw.js` 第一行附近的 `CACHE_VERSION` 加 1（如 `'v1'` → `'v2'`），旧缓存会被自动清理。离线缓存采用"网络优先"，有网时总会拿到最新文件。

## 调试与自检

- 网址后面加 `?debug=1`，页面左上角会显示每次的目标格、转盘角度、反算结果和 ✓/✗。
- 自动校验（需要 Node.js 和 Playwright）：先启动上面的本地服务器，再运行：

```bash
node tools/test-wheel.js
```

脚本会模拟安卓手机：
1. 连转 100 次，检查**指针尖下方实际画出来的扇区**、算法结果、显示文字三者一致；
2. 用正常 2 秒动画转 10 次，转动中连点 15 下，检查不会提前出结果或重复触发；
3. 检查 360×640、360×740、412×915 屏幕下一屏完整显示、不需滚动；
4. 对 2~12 项转盘的角度算法做约 3.9 万次穷举；
5. 检查分类切换、编辑选项（含 12 项 / 2 项转盘一致性）、记录、刷新后保留、数据损坏自动恢复。

## 角度算法

- 12 点钟方向为 0°，顺时针增加；扇区 `i` 占 `[i·slice, (i+1)·slice)`，`slice = 360 / N`。
- 先随机选目标 `targetIndex`，在扇区 20%~80% 处取停止点，算出正向增量，再加 5 整圈。
- 停转后用最终角度反算指针所指扇区，与目标校验；显示的文字只来自 `targetIndex`。
